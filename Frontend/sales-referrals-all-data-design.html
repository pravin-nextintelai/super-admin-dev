Notes for developers

  • Route: /admin/sales-referrals/data, super admin only. Opened from the new All referral data button on Sales Referrals.
  • Filters (owner, code, type, plan status, Direct, search, date) apply to the cards, both tabs and the CSV. Clicking an owner name in the table sets the owner filter.
  • "By workspace" = one row per workspace; expanding a row shows its plan history and referral details. "Plan purchases" = one row per paid event across all workspaces.
  • Plan history (purchases, upgrades, renewals, amounts, payment IDs) comes from the payments service, not IAM. This needs a new backend endpoint.
  • CSV should be generated by the server for the active filters (streamed, so large exports work). Escape cells starting with = + - @ to prevent spreadsheet formula injection.
  • Amounts in INR, dates in IST. Totals here are sample data that match the current Sales Referrals overview.
